## 一个想法的开始

我是软件工程专业的大二学生。学习的内容越来越多之后，我发现：如果只是看完、做完，却没有认真整理，很多理解会很快变得模糊。

于是，我想拥有一个真正属于自己的空间。这里不只是展示结果，也记录那些没有一次成功的尝试、逐渐想通的概念，以及学习过程中真实的心情。

## 我会在这里记录什么

- **编程学习**：新知识、问题排查和练习总结。
- **读书笔记**：值得留下的观点，以及我自己的理解。
- **项目复盘**：做了什么、踩过什么坑、下次怎样做得更好。
- **生活记录**：代码之外，那些同样构成我的日常。

## 为什么选择 Markdown

Markdown 让我可以把注意力放在内容上。例如，一段代码可以这样记录：

```ts
const keepLearning = true;
const writeItDown = (idea: string) => `今天学到了：${idea}`;
```

文章保存在本地，也会通过 Git 留下每次修改的历史。这意味着博客和学习过程一样，可以一点点生长。

## 写给未来的自己

我不期待这里从第一天起就足够完美。比起漂亮的起点，我更希望它拥有长久的更新。

如果未来的我重新读到这篇文章，希望还能记得：开始记录，不是因为已经知道很多，而是因为愿意认真走过正在学习的每一步。
